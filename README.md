# Taj Hotel Billing System

A Python desktop billing and management application built with `tkinter` for handling food orders, calculating totals, and managing order history.

## Features

- Food item selection
- Quantity entry for each menu item
- Automatic price calculation
- 5% tax calculation
- Subtotal and total billing
- Order history tracking
- Previous order navigation
- Price list display
- Built-in calculator
- Digital clock in the interface
- Clean hotel-style GUI

## Project Structure

- `billing_system.py` - Main application file

## Requirements

- Python 3.x
- Tkinter (usually included with Python installations)

## How to Run

1. Open a terminal in the project folder.
2. Run:

```bash
python billing_system.py
```

If your system uses `python3` instead of `python`, use:

```bash
python3 billing_system.py
```

## Example Usage

- Select food items from the menu.
- Enter quantities.
- Click the calculation buttons to determine the price and total.
- Review order history and working totals.
- Use the built-in calculator and digital clock as needed.
